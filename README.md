# 프로젝트 팔구삼(893, palgoosam)
**893(팔구삼)은 중고 물품을 실시간으로 경매할 수 있는 온라인 플랫폼입니다.**
단순한 직거래 방식을 벗어나 경매 방식을 통해서 투명하고 공정한 가격 경쟁을 유도하여,
판매자와 구매자 모두가 만족할 수 있는 가격을 형성할 수 있도록 돕습니다.
